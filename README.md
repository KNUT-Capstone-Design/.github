# 조직 소개 및 협업 안내

한국교통대학교 캡스톤디자인 팀의 조직 프로필과 공통 작업 안내를 관리하는 저장소입니다.

## 파일 구성

- [profile/README.md](profile/README.md): 조직 소개, MVP 범위, 팀원, 저장소 및 설계 문서 안내
- [CONTRIBUTING.md](CONTRIBUTING.md): 팀 작업 분담과 이슈·PR 작성 가이드

## 관리 기준

- 상세 기능·시스템·DB·API 계약은 [Docs 저장소](https://github.com/KNUT-Capstone-Design/KNUT-Capstone-Design-docs)에서 관리합니다.
- 소개는 승인된 결정과 현재 설계 초안을 구분해서 요약합니다.
- 기능 범위, 기술 스택, 역할이 바뀌면 조직 소개도 함께 갱신합니다.
- 아직 구현하거나 검증하지 않은 기능을 완료된 기능으로 표시하지 않습니다.

문서와 조직 소개 관리는 PM/Docs 담당 영역이며 팀원이 변경 내용을 함께 검토합니다.
