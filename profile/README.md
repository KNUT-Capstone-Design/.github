# 스미싱 예방 교육 및 탐지 시스템

스미싱 예방 교육과 의심 메시지·URL·QR 코드·이미지 판별 기능을 결합한 웹 기반 보안 서비스입니다.

## 주요 기능

- 가짜 로그인 페이지 탐지  
  - 네이버, 구글, 쿠팡 사칭 사례 판별

- APK 설치 유도 메시지 탐지  
  - 쿠팡, 청첩장, 택배 사칭 등 설치 유도 문구 분석

- URL 위험도 분석  
  - 대출, 공공기관 사칭, 주식 리딩, 단체예약·술 구매 유도 등 스미싱 URL 탐지

- QR 코드 검사  
  - QR 코드에서 URL을 추출하고 위험도를 분석

- 조작 이미지 판별  
  - 업로드된 사진의 조작 의심 여부 확인

- 예방 교육 콘텐츠  
  - 실제 스미싱 사례와 퀴즈를 통해 사용자의 대응 능력 향상

## 개발 목표

복잡한 앱 설치 없이 웹에서 간단히 의심 요소를 검사하고,  
스미싱의 위험 요소와 예방법을 함께 제공하는 경량형 예방 시스템을 구현합니다.
